Aggiornamento remoto dei parametri

Richiede un broker raggiungibile via WebSocket (es. Mosquitto con listener ws attivo). Ogni topic riceve il valore numerico di un solo parametro come payload (es. "0.75").

Si collega direttamente a un server WebSocket (nessun broker, nessun topic). Ogni messaggio ricevuto deve essere un oggetto JSON con una o più delle chiavi x0, r, n, es. {"r": 2.8} oppure {"x0": 0.4, "n": 60}.

Nota sul comportamento: per r < 3 la sequenza converge a un punto fisso; per 3 ≤ r < 3.57 circa compaiono cicli periodici (biforcazioni); oltre r ≈ 3.57 la mappa entra in regime caotico. Prova a variare r per osservare questi diversi regimi.
