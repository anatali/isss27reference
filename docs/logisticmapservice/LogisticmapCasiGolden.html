Mappa Logistica: il testing

La mappa logistica è modellata dall'equazione alle differenze:

xn+1 = r · xn · (1 - xn)

con dominio xn ∈ [0, 1] e parametro di controllo r ∈ [0, 4].

A seconda del valore del parametro r ∈ [0, 4] e delle condizioni iniziali x0 ∈ [0, 1], il comportamento dinamico (traiettoria) della funzione può variare notevolmente: da punti fissi convergenti, a cicli periodici, fino ad un regime completamente caotico. Sorge dunque un problema: come impostare un test che faccia asserzioni su valori impredicibili?

Un approccio basato sul Property-Based Testing permette di verificare proprietà invarianti che DEVONO valere per qualunque combinazione di parametri nel dominio ammesso, indipendentemente dalla natura convergente, periodica o caotica della serie generata. Ad esempio:

  • Lunghezza Corretta: La chiamata a computeSeries(r, x0, n) deve restituire un array di dimensione esatta n + 1 (includendo il valore iniziale x0 e gli n passi successivi).
  • Limitatezza dei Valori (Invarianza del Dominio): Se x0 ∈ [0, 1] e r ∈ [0, 4], ogni valore xt generato nella sequenza deve rimanere nell'intervallo [0, 1].
  • Casi Limite (Punti Fissi Invarianti): Se x0 = 0, la sequenza deve rimanere identicamente 0 per tutti gli step. Se r = 0, tutti i valori dopo x0 devono azzerarsi.
  • Ricorrenza Puntuale: Ogni elemento xi+1 dell'array risultante deve soddisfare la relazione xi+1 ≈ r · xi · (1 - xi) nei limiti di approssimazione della formattazione o di calcolo della classe.
  • Determinismo: Chiamate successive del metodo con gli stessi parametri devono produrre esattamente la stessa sequenza di output.

Soluzioni in Forma Chiusa e Casi Golden

Sebbene per r = 4.0 la mappa esibisca un comportamento altamente caotico ed ergodico su quasi tutto l'intervallo, esistono r e punti iniziali particolari x0 per i quali la traiettoria ammette una soluzione esplicita in forma chiusa.

Questi casi analitici rappresentano i test golden ideali per verificare la correttezza dei simulatori numerici senza accumulare gli errori di arrotondamento dell'aritmetica in virgola mobile.

1. Punti Fissi Banali e Cicli d'Attrattore (r ≤ 3.0)

I punti fissi si ottengono risolvendo l'equazione stazionaria x* = f(x*), ovvero
x* = r · x* · (1 - x*).

A. L'Estinzione (x* = 0)

Per qualsiasi r ≤ 1.0 e per qualunque valore iniziale x0 ∈ [0, 1]:

lim n → ∞ xn = 0

Caso Golden: Se x0 = 0 oppure x0 = 1, allora xn = 0 per tutti gli n ≥ 1.

B. Il Punto Fisso Stabile (x* = 1 - 1/r)

Per 1.0 < r ≤ 3.0, il sistema converge verso il punto fisso stazionario x* = 1 - 1/r.

Caso Golden: Se si imposta x0 = 1 - 1/r, la successione risulta perfettamente costante:

xn = 1 - 1/r   ∀ n ≥ 0
Esempii: 
	Per r = 3.0, con x0 = 2/3 ≈ 0.6666667, si ha xn = 2/3 per qualsiasi passo n.
	Per r = 2.0, con x0 = 0.7, si ha xn -> 0.5

2. Il Regime Caotico Massimo (r = 4.0) in Forma Chiusa

Quando r = 4.0, il sistema è pienamente caotico, ma ammette soluzioni esatte attraverso l'applicazione di opportune trasformazioni analitiche.

A. Soluzione Analitica Generale tramite Cambio di Variabile Trigonometrico

Applicando il cambio di variabile xn = sin2(θn), l'equazione della mappa si riduce all'identità trigonometrica per l'angolo doppio:

xn+1 = 4 · sin2(θn) · (1 - sin2(θn)) = 4 · sin2(θn) · cos2(θn) = sin2(2θn)

Poiché ad ogni passo l'angolo raddoppia (θn = 2n · θ0), si ricava la soluzione esplicita in forma chiusa per r = 4.0:

xn = sin2(2n · arcsin(√x0))
Lo sviluppo passo-passo di questa relazione si trova in Appendice

B. Punti Fissi Involutivi e Pre-Immagini dello Zero

  • Punto fisso in 3/4: Scegliendo x0 = 3/4 = 0.75 (corrispondente a θ0 = π/3), la successione rimane costante: xn = 0.75 per tutti gli n ≥ 0. Infatti 4 · (3/4) · (1/4) = 3/4.
  • Singolarità centrale e crollo allo zero: Se x0 = 1/2 = 0.5 (corrispondente a θ0 = π/4), si ottiene x1 = 1.0 e, da x2 in poi, xn = 0.0 per ogni n ≥ 2.

C. Orbite Periodiche Esatte (Angoli Razionali)

Se si sceglie x0 = sin2(θ0) con θ0 = π · p / q (con p, q interi), la traiettoria non degenera nel caos ma genera cicli periodici o eventualmente periodici analiticamente prevedibili:

  • Ciclo di Periodo 2 (q = 5): Scegliendo x0 = sin2(π/5) = (5 - √5) / 8 ≈ 0.3454915, la successione ( n <= 20 ) oscilla indefinitamente tra due valori:
    0.3454915 → 0.9045085 → 0.3454915 → 0.9045085 …;
  • Ciclo di Periodo 3 (q = 7): Scegliendo x0 = sin2(π/7) ≈ 0.188255, la successione genera un ciclo esatto di periodo 3:
    0.188255 → 0.611260 → 0.950484 → 0.188255 …

3. Soluzione Analitica Esatta per r = 2.0

Quando r = 2.0, si applica la trasformazione algebrica xn = (1 - yn) / 2:

yn+1 = 1 - 2xn+1 = 1 - 4xn(1 - xn) = (1 - 2xn)2 = yn2

Ricavando la relazione di ricorrenza per elevamento a potenza yn = y0(2n), si ottiene la soluzione in forma chiusa per r = 2.0 valida per qualsiasi punto iniziale x0:

xn = [1 - (1 - 2x0)2n] / 2

Caso Golden (r = 2.0, x0 = 0.1):

xn = [1 - (0.8)2n] / 2

Poiché (0.8)2n tende a zero a velocità super-esponenziale, la formula permette di calcolare la posizione esatta al passo n con precisione arbitraria senza iterare la funzione.

Nota per l'implementazione nei test: I test per i cicli periodici o per le formule trigonometriche/esponenziali devono prevedere una tolleranza numerica (es. delta = 1e-12) a causa dell'approssimazione dei calcoli in floating-point (double).

Appendice: Dimostrazione Analitica Passo-Passo per r = 4.0

Di seguito si riporta (come proposto da Gemini AI) la derivazione matematica formale che consente di trasformare la mappa ricorsiva non lineare per r = 4.0 in una mappa lineare di raddoppio dell'angolo.

  1. Definizione e problema iniziale:

    Sia data l'equazione alle differenze per r = 4:

    xn+1 = 4 · xn · (1 - xn),    con xn ∈ [0, 1]
  2. Cambio di variabile trigonometrico:

    Poiché l'immagine della funzione sin2(θ) coincide con l'intervallo [0, 1], poniamo:

    xn = sin2(θn)

    Sostituendo nell'equazione della mappa per il passo n+1:

    xn+1 = 4 · sin2(θn) · (1 - sin2(θn))
  3. Semplificazione mediante identità fondamentale:

    Sfruttando la relazione fondamentale della trigonometria 1 - sin2(θ) = cos2(θ), l'espressione diventa:

    xn+1 = 4 · sin2(θn) · cos2(θn)
  4. Applicazione della formula di duplicazione dell'angolo:

    Riscriviamo il secondo membro come un unico quadrato perfetto:

    xn+1 = (2 · sin(θn) · cos(θn))2

    Ricordando la formula dell'angolo doppio 2 · sin(θ) · cos(θ) = sin(2θ), otteniamo:

    xn+1 = sin2(2θn)
  5. Mappa lineare di raddoppio dell'angolo:

    Uguagliando la definizione xn+1 = sin2(θn+1) con il risultato ottenuto sin2(2θn), ricaviamo la legge di evoluzione angolare:

    θn+1 = 2 · θn

    Sviluppando la successione per n passi a partire dalla condizione iniziale θ0:

    θn = 2n · θ0
  6. Formulazione esplicita finale:

    Invertendo la relazione iniziale x0 = sin2(θ0) rispetto all'angolo θ0:

    θ0 = arcsin(√x0)

    Sostituendo θ0 nell'espressione dell'angolo al passo n e reinserendo il tutto nella variabile originale xn = sin2(θn), si giunge alla soluzione chiusa analitica:

    xn = sin2(2n · arcsin(√x0))
